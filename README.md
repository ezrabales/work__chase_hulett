## Description

This site is made up into three main parts; Cinema, Videography, and Admin. The Cinema and Videopraphy pages are meant to showcase the work and character of the man, Chase Hulett. He has done many impressive things in the cinema world and has found beautiful shots with his skills in videography. The admin page is for the admin's entertainment, using a third-party API, it finds all the films that came out each day, and showcases the one with the greatest popularity.

I used a lot of flex displays as well as some grid displays to showcase the embedded videos and descriptions. I also was able to slide the components into the screen based on the users scroll position by using JavaScript and the "transition" CSS component.

## Future Development
